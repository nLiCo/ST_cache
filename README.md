# ST_cache — 캠퍼스 숨은 장소 찾기

### 👉 https://nlico.github.io/ST_cache/

**폰으로 열어 주세요.** 위치 권한을 허용해야 합니다.

## 어떤 앱인가요?

학교 캠퍼스는 넓은데, 매일 다니는 길 말고는 잘 모르는 곳이 많습니다. ST_cache는 그런 숨은 장소를 직접 찾아가 보게 하는 지오캐싱 웹앱입니다.

지도에 위치를 알려 주지 않습니다. **장소 사진 한 장만 보고** 어디인지 추측해서 찾아가는 게 재미입니다.

## 노는 법

1. 화면 아래 사진 목록에서 찾고 싶은 장소를 고릅니다. 이름은 `???`로 가려져 있습니다.
2. 사진을 보고 어디일지 생각해서 걸어갑니다.
3. 도착했다 싶으면 **"📍 여기가 맞나 확인"** 을 누릅니다.
4. 맞으면 장소 이름과 이야기가 열리고, 지도에 별이 생깁니다.

틀려도 얼마나 떨어져 있는지는 알려 주지 않습니다. 사진을 다시 잘 보세요.

- 건물 사이나 실내에서는 GPS가 부정확할 수 있습니다. "위치가 부정확해요"가 뜨면 트인 곳에서 잠깐 기다렸다가 다시 눌러 보세요.
- 지금 버전은 찾은 기록을 그 폰의 브라우저에만 저장합니다. 로그인 기능이 붙으면 서버에 저장합니다.

## 개발 중입니다

지금 사이트는 **프로토타입**입니다(장소 12곳, 이름은 임시). 12월 초까지 아래 기능을 붙이고 있습니다.

- 구글 로그인과 닉네임
- **직접 장소 올리기**: 내가 아는 숨은 장소를 현장에서 찍어 올리면, 다른 사람이 찾으러 옵니다.
- **점수와 랭킹**: 많이 찾을수록, 다른 사람들이 잘 못 찾는 곳을 찾을수록 점수가 높습니다.

써 보고 불편한 점이나 아이디어가 있으면 알려 주세요.

## 개인정보

개인 과제로 만든 비상업 앱입니다. 꼭 필요한 정보만 받고, 다른 목적으로 쓰지 않습니다.

**구글 로그인으로 받는 것**
- 이메일, 이름, 프로필 사진만 받습니다. 구글 비밀번호, Gmail, 드라이브, 연락처 같은 정보는 받지 않습니다.
- 이메일과 이름은 로그인에만 씁니다. **다른 사용자에게는 직접 정한 닉네임만 보입니다.**
- 이메일과 이름은 관리자(개발자 한 명)만 Supabase 관리 화면에서 볼 수 있습니다.

**위치**
- "확인" 버튼을 누른 순간의 위치만 서버로 보내 그 자리에서 판정하고, **위치 자체는 저장하지 않습니다.** 이동 경로도 저장하지 않습니다.
- 저장되는 건 "어떤 장소에서 확인을 눌렀는지, 어떤 장소를 찾았는지"와 그 시각입니다. 점수 계산에 씁니다.
- 장소를 올리면 그 장소의 좌표가 저장됩니다. 이 좌표는 다른 사용자에게 보이지 않고, 찾았는지 판정할 때만 씁니다.

**사진**
- 올리는 사진은 위치 정보(EXIF)를 지우고 크기를 줄여서 저장합니다.
- 승인된 장소의 사진은 누구나 볼 수 있습니다. 사람 얼굴이나 개인 정보가 나오지 않게 찍어 주세요.

**보관과 삭제**
- 데이터는 Supabase(서울 지역 서버)에 저장됩니다.
- 계정과 기록을 지우고 싶으면 개발자에게 알려 주세요. 계정, 닉네임, 찾은 기록, 올린 장소를 모두 지웁니다.
- 과제가 끝나고 서비스를 닫으면 저장된 데이터를 모두 지웁니다.

## 개발자용

오픈소스 소프트웨어 과제로 만드는 프로젝트입니다. 기획, 기술 스택, DB 설계, 일정은 [SPEC.md](SPEC.md)에 있습니다.
