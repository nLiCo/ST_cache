# ST_cache — 캠퍼스 숨은 장소 찾기

### 👉 https://nlico.github.io/ST_cache/

**폰으로 열어 주세요.** 위치 권한을 허용해야 합니다.

## 어떤 앱인가요?

학교 캠퍼스는 넓은데, 매일 다니는 길 말고는 잘 모르는 곳이 많습니다. ST_cache는 그런 숨은 장소를 직접 찾아가 보게 하는 지오캐싱 웹앱입니다.

지도에 위치를 알려 주지 않습니다. **장소 사진 한 장만 보고** 어디인지 추측해서 찾아가는 게 재미입니다. 내가 아는 숨은 장소를 찍어 올려서 다른 사람이 찾으러 오게 할 수도 있습니다.

## 노는 법

사진 보기는 로그인 없이 됩니다. 확인 버튼과 장소 올리기는 구글 로그인 후 닉네임을 정해야 쓸 수 있습니다.

1. 첫 화면의 사진 목록에서 찾고 싶은 장소를 누릅니다. 이름은 `???`로 가려져 있습니다.
2. 큰 사진과 힌트를 보고 어디일지 생각해서 걸어갑니다. 내 위치는 [지도] 탭에서 볼 수 있고, [사진] 탭을 누르면 보던 사진으로 돌아옵니다.
3. 도착했다 싶으면 **"📍 여기가 맞나 확인"** 을 누릅니다.
4. 맞으면 장소 이름과 이야기가 열리고, 지도에 별이 생깁니다.

폰에서는 아래 탭(📷 사진 / 🗺 지도 / ➕ 등록)으로 화면을 오갑니다. PC에서는 지도 옆에 사진 목록이 함께 보입니다.

틀려도 얼마나 떨어져 있는지는 알려 주지 않습니다. 사진을 다시 잘 보세요.

- 건물 사이나 실내에서는 GPS가 부정확할 수 있습니다. "위치가 부정확해요"가 뜨면 트인 곳에서 잠깐 기다렸다가 다시 눌러 보세요.
- 찾은 기록은 내 계정에 저장됩니다. 다른 폰에서 로그인해도 그대로 보입니다.
- 내가 올린 장소는 내가 찾을 수 없습니다.

## 장소 올리기

1. 아래 탭(PC는 위쪽 메뉴)에서 **[등록]** 을 누릅니다.
2. 올리고 싶은 자리에 서서 위치 정확도가 30m 이하가 될 때까지 기다립니다. "이 자리에 서서 잠시 기다려 주세요"가 뜨면 조금만 가만히 있어 주세요.
3. **"📷 사진 찍기"** 를 누르면 카메라가 열립니다. **버튼을 누른 순간의 위치가 장소 위치가 됩니다.** 갤러리의 예전 사진은 올릴 수 없습니다.
4. 이름(필수, 30자), 힌트(선택, 100자), 이야기(선택, 500자, 찾은 사람에게만 보임)를 적고 등록합니다.
5. 관리자가 승인하면 다른 사람에게 공개됩니다.

"서버와 연결이 잠시 불안정해요"가 뜨면 적은 내용은 그대로 남아 있으니 잠시 후 등록 버튼만 다시 눌러 주세요.

## 개발 중입니다

12월 초까지 아래 기능을 붙이고 있습니다.

- **점수와 랭킹**: 많이 찾을수록, 다른 사람들이 잘 못 찾는 곳을 찾을수록 점수가 높습니다.
- **내 정보**: 내 점수와 순위, 찾은 장소, 올린 장소와 승인 상태

처음 넣어 둔 12곳의 이름은 아직 임시입니다. 써 보고 불편한 점이나 아이디어가 있으면 알려 주세요.

## 개인정보

개인 과제로 만든 비상업 앱입니다. 꼭 필요한 정보만 받고, 다른 목적으로 쓰지 않습니다.

**구글 로그인으로 받는 것**
- 이메일, 이름, 프로필 사진만 받습니다. 구글 비밀번호, Gmail, 드라이브, 연락처 같은 정보는 받지 않습니다.
- 이메일과 이름은 로그인에만 씁니다. **다른 사용자에게는 직접 정한 닉네임만 보입니다.** 내가 올린 장소의 카드에는 내 닉네임이 표시됩니다.
- 이메일과 이름은 관리자(개발자 한 명)만 Supabase 관리 화면에서 볼 수 있습니다.

**위치**
- "확인" 버튼을 누른 순간의 위치만 서버로 보내 그 자리에서 판정하고, **위치 자체는 저장하지 않습니다.** 이동 경로도 저장하지 않습니다.
- 저장되는 건 "어떤 장소에서 확인을 눌렀는지, 어떤 장소를 찾았는지"와 그 시각입니다. 점수 계산에 씁니다.
- 장소를 올리면 그 장소의 좌표와 GPS 정확도가 저장됩니다. 찾기 전의 사람에게는 보이지 않고, 그 장소를 찾은 사람의 지도에만 별로 표시됩니다.

**사진**
- 올리는 사진은 위치 정보(EXIF)를 지우고 크기를 줄여서 저장합니다.
- 승인된 장소의 사진은 누구나 볼 수 있습니다. 사람 얼굴이나 개인 정보가 나오지 않게 찍어 주세요.

**보관과 삭제**
- 데이터는 Supabase(서울 지역 서버)에 저장됩니다.
- 계정과 기록을 지우고 싶으면 개발자에게 알려 주세요. 계정, 닉네임, 찾은 기록, 올린 장소를 모두 지웁니다.
- 서비스를 닫을 때 저장된 데이터를 모두 지웁니다.

## 개발자용

오픈소스 소프트웨어 과제로 만드는 프로젝트입니다. 기획, 기술 스택, DB 설계, 일정은 [SPEC.md](SPEC.md)에 있습니다.

- 순수 HTML / CSS / JavaScript(ES 모듈, 빌드 없음), Leaflet + OpenStreetMap, Supabase(구글 로그인, Postgres + RLS, Storage), GitHub Pages
- 로컬 실행: `python -m http.server 8765` → http://localhost:8765/
- PC에서 테스트: 주소 끝에 `?mock=1`을 붙이면 지도를 누른 곳을 내 위치로 씁니다. `?debug=1`은 위치·정확도 패널을 보여 줍니다.
- 테스트: `node --test "tests/*.test.mjs"` (Node 22 이상)
- DB: `supabase/migrations/`의 SQL을 Supabase SQL Editor에서 순서대로 실행합니다. 주소와 공개 키는 `js/config.js`에 있습니다(공개 키라 페이지에 들어가도 되고, 권한은 RLS가 막습니다).
