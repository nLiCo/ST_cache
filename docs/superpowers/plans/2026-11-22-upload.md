# ② 장소 등록 화면 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로그인한 사람이 현장에서 사진을 찍어 장소를 올리는 `#upload` 화면과 해시 라우팅을 만든다.

**Architecture:** 판단 규칙(위치 상태, 사진 시각, 크기, 입력 검사, 안내 문구)은 DOM·CDN에 기대지 않는 `js/upload-rules.js`에 모아 Node 기본 테스트(`node --test`)로 검사한다. 화면·업로드는 `js/upload.js`, 화면 전환은 `js/main.js`가 맡는다. DB는 바꾸지 않는다.

**Tech Stack:** 순수 HTML/CSS/JS(ES 모듈), Supabase JS 2.119.0(CDN), Leaflet 1.9.4, exifr 7.1.3(CDN, `https://cdn.jsdelivr.net/npm/exifr@7.1.3/dist/lite.esm.mjs`), 테스트는 Node 24의 `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-22-upload-design.md` (+ SPEC.md "② 장소 등록")

## Global Constraints

- 빌드 도구·프레임워크·npm 의존성 없음. 라이브러리는 CDN에서 정확한 버전으로.
- 사진 찍기 조건: 정확도 ≤ 30m, 위치가 30초 안에 갱신됨(가짜 위치 모드는 시간 무관, `geo.js`의 `hasFreshPosition`).
- 좌표·정확도는 **카메라 버튼을 누른 순간** 값으로 고정(`pinned`). 다시 찍으면 새로 고정.
- 사진 시각 ≥ 카메라 버튼 누른 시각 − 60000ms. 시각은 EXIF `DateTimeOriginal`, 없으면 `file.lastModified`.
- 이름 필수 1~30자(앞뒤 공백 제거 후), 힌트 ≤100자, 이야기 ≤500자. 빈 힌트·이야기는 `null`로 넣는다.
- 사진: 긴 변 1280px 이하(작으면 그대로), JPEG 품질 0.85, 경로 `<user id>/<crypto.randomUUID()>.jpg`, 버킷 `photos`.
- insert 칸: `name, hint, story, photo_path, lat, lng, accuracy`만. `.select()`를 붙이지 않는다(select 권한 없음).
- 안내 문구는 한국어 존댓말 "~요"체. 화면에 거리·좌표 숫자는 정확도(±m)만 보인다.
- 커밋: Conventional Commits, 한국어 제목·본문, 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. 카메라에서 돌아오지 않고 취소(파일 없음) → 이전 사진·`pinned`가 그대로 남거나, 사진이 없으면 등록 버튼이 꺼져 있어야 한다.
2. 등록 버튼을 두 번 빠르게 누름 → 장소가 한 번만 들어가야 한다(진행 중 버튼 비활성).
3. 등록 화면에 있는 동안 로그아웃하거나 다른 계정으로 바뀜 → 입력과 `pinned`가 지워지고 로그인 안내로 바뀌어야 한다.
4. 아주 작은 사진(긴 변 < 1280) → 키우지 않는다. 세로 사진 → 긴 변이 세로로 잡힌다. (Task 1 `fitSize` 테스트)
5. 공백만 있는 이름 / 정확히 30자 / 31자 → 앞뒤 공백 제거 후 판단. (Task 1 `validateFields` 테스트)

### Task 1: 판단 규칙 모듈 `js/upload-rules.js`

**Files:**
- Create: `js/upload-rules.js`
- Create: `tests/upload-rules.test.mjs`

**Interfaces:**
- Produces (모두 순수 함수, import 없음):
  - `export const MAX_UPLOAD_ACCURACY_M = 30`
  - `positionStatus(pos: {accuracy:number}|null, fresh: boolean) -> "none" | "inaccurate" | "ok"` — `pos`가 없거나 `fresh`가 false면 `"none"`, 정확도 > 30이면 `"inaccurate"`.
  - `photoTakenAt(exifDate: Date|undefined|null, lastModified: number) -> number` — 유효한 EXIF Date면 그 ms, 아니면 `lastModified`.
  - `isFreshPhoto(takenAtMs: number, pinnedAtMs: number) -> boolean` — `takenAtMs >= pinnedAtMs - 60000`.
  - `fitSize(width: number, height: number, maxSide = 1280) -> {width:number, height:number}` — 비율 유지, 반올림, 키우지 않음.
  - `photoPath(userId: string, id: string) -> string` — `` `${userId}/${id}.jpg` ``.
  - `validateFields({name, hint, story}: strings) -> string|null` — 오류 문구 또는 `null`. 문구: `"이름을 적어 주세요."`, `"이름은 30자까지 적을 수 있어요."`, `"힌트는 100자까지 적을 수 있어요."`, `"이야기는 500자까지 적을 수 있어요."`
  - `placeRow(fields, pinned: {lat,lng,accuracy}, path: string) -> {name, hint, story, photo_path, lat, lng, accuracy}` — 모든 문자열 trim, 빈 힌트·이야기는 `null`.
  - `uploadNotice(role: string) -> string` — `trusted`/`admin`: `"등록했어요! 바로 공개됐어요."`, 그 밖: `"등록했어요! 관리자가 승인하면 공개돼요."`

```js
test("positionStatus", () => {
  assert.equal(positionStatus(null, true), "none");
  assert.equal(positionStatus({ accuracy: 5 }, false), "none");
  assert.equal(positionStatus({ accuracy: 30 }, true), "ok");
  assert.equal(positionStatus({ accuracy: 30.1 }, true), "inaccurate");
});
test("photoTakenAt: EXIF 우선, 없거나 잘못되면 파일 시각", () => {
  assert.equal(photoTakenAt(new Date(1000), 5000), 1000);
  assert.equal(photoTakenAt(undefined, 5000), 5000);
  assert.equal(photoTakenAt(new Date("x"), 5000), 5000);
});
test("isFreshPhoto: 버튼 누르기 1분 전까지 허용", () => {
  const pinned = 1_000_000;
  assert.equal(isFreshPhoto(pinned - 60000, pinned), true);
  assert.equal(isFreshPhoto(pinned - 60001, pinned), false);
  assert.equal(isFreshPhoto(pinned + 30000, pinned), true);
});
test("fitSize", () => {
  assert.deepEqual(fitSize(4000, 3000), { width: 1280, height: 960 });
  assert.deepEqual(fitSize(3000, 4000), { width: 960, height: 1280 });
  assert.deepEqual(fitSize(800, 600), { width: 800, height: 600 });
});
test("photoPath", () => assert.equal(photoPath("u1", "abc"), "u1/abc.jpg"));
test("validateFields", () => {
  assert.equal(validateFields({ name: "   ", hint: "", story: "" }), "이름을 적어 주세요.");
  assert.equal(validateFields({ name: " " + "가".repeat(30) + " ", hint: "", story: "" }), null);
  assert.equal(validateFields({ name: "가".repeat(31), hint: "", story: "" }), "이름은 30자까지 적을 수 있어요.");
  assert.equal(validateFields({ name: "a", hint: "가".repeat(101), story: "" }), "힌트는 100자까지 적을 수 있어요.");
  assert.equal(validateFields({ name: "a", hint: "", story: "가".repeat(501) }), "이야기는 500자까지 적을 수 있어요.");
});
test("placeRow: trim, 빈 칸은 null", () => {
  assert.deepEqual(
    placeRow({ name: " 돌계단 ", hint: "  ", story: " 옛 길 " }, { lat: 1, lng: 2, accuracy: 3, time: 9 }, "u/p.jpg"),
    { name: "돌계단", hint: null, story: "옛 길", photo_path: "u/p.jpg", lat: 1, lng: 2, accuracy: 3 });
});
test("uploadNotice", () => {
  assert.equal(uploadNotice("admin"), "등록했어요! 바로 공개됐어요.");
  assert.equal(uploadNotice("trusted"), "등록했어요! 바로 공개됐어요.");
  assert.equal(uploadNotice("user"), "등록했어요! 관리자가 승인하면 공개돼요.");
});
```

- 정확도 줄: `positionStatus` 결과로 — `none`: MOCK이면 "탐색 지도에서 먼저 위치를 찍어 주세요", 아니면 "위치를 확인하는 중이에요"; `inaccurate`: "현재 위치 정확도: ±n m" + "이 자리에 서서 잠시 기다려 주세요"; `ok`: "현재 위치 정확도: ±n m". 사진 찍기 버튼은 `ok`일 때만 켠다. `onPosition`마다, 그리고 30초가 지나 낡는 경우를 잡도록 5초마다 다시 그린다.
- 사진 찍기 버튼: `pinned = { lat, lng, accuracy, time: Date.now() }`로 고정(가짜 위치도 시각은 `Date.now()`), 파일 입력 `value`를 비우고 `click()`.
- 파일 `change`: 파일이 없으면(취소) 아무것도 바꾸지 않는다. 있으면 exifr `parse(file, ["DateTimeOriginal"])`(실패하면 `undefined`) → `photoTakenAt` → `isFreshPhoto`가 false면 사진을 버리고 오류 줄 "방금 찍은 사진만 올릴 수 있어요. 다시 찍어 주세요." 통과하면 미리보기(`URL.createObjectURL`, 이전 것은 revoke)와 "위치 고정됨 ±n m".
- 등록 버튼: 사진과 `pinned`가 있을 때만 켠다. 누르면 `validateFields` → 진행 중 버튼 비활성·"올리는 중…" → `createImageBitmap(file, { imageOrientation: "from-image" })` + canvas(`fitSize`) → `toBlob("image/jpeg", 0.85)` → `supabase.storage.from("photos").upload(path, blob, { contentType: "image/jpeg" })` → `supabase.from("places").insert(placeRow(...))` → `showToast(uploadNotice(role))`, 모두 비우고 `reloadPlaces()`. 업로드·insert 오류는 오류 줄에 `올리지 못했어요 (${message})`, 버튼 다시 켬.
